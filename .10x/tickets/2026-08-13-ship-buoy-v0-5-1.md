# Ship Buoy v0.5.1

## Outcome

Ship only the reviewed GitHub-repository containment fix and minimum
installation/first-index onboarding as GitHub-only Buoy v0.5.1.

## Executable sequence

1. Validate the containment task locally on locked Python 3.11 and 3.13 and
   obtain an independent source/test review.
2. Publish the reviewed task branch, require public CI, and have a separate
   integration role squash-merge it into `develop`.
3. Have a separate release role merge-commit the exact `develop` tree into
   `main` after the four release-readiness checks pass.
4. Build the exact v0.5.1 wheel and source archive once from that `main` commit
   with the documented exact-version override and deterministic environment;
   validate and hash them, create the one-time annotated tag and GitHub Release,
   then download and verify both assets and clean-install the wheel.
5. Publish the existing draft security advisory only after the installed
   release passes the documented offline smoke path.
6. Through a separate reviewed documentation PR, replace the pending v0.5.1
   changelog marker with the authoritative UTC GitHub Release date and verify
   the read-only validator reports published history through v0.5.1.

## Acceptance

- `buoy plan` never follows a Git-tracked link, submodule, special entry, or
  replaced unsafe checkout path; normal tracked regular files behave as before.
- End-user installation is separate from contributor setup and the first-index
  guide shows plan, dry-run review, approved apply, and explicit retrieval.
- Existing v0.5.0 hosted state is untouched.
- v0.5.1 contains exactly the wheel and source archive named in
  `.10x/decisions/v0-5-1-one-time-manual-security-release.md`; downloaded
  hashes and a clean installation match the reviewed build.
- The advisory records v0.5.1 as fixed and is published only after verification.

## Exclusions

Reusable release automation, PyPI, Turbopuffer or namespace operations,
stale-row deletion, branch-protection changes, direct/force pushes, unrelated
hardening, and other product development.
